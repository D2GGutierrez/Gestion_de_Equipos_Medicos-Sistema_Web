# Ejercicio 2 – Proyecto React con Vite

```
npm create vite@latest frontend -- --template react
cd frontend
npm install
npm run dev
```
Resultado: `VITE v8.3.4 ready` en http://localhost:5173/ (React 19, JavaScript).

- `captura_terminal_vite.png`: salida de `npm install` y `npm run dev`.
- `captura_pagina_inicial.png`: página inicial de Vite + React en http://localhost:5173/ ("Get started", contador).

Nota: el proyecto se generó y se probó en el entorno Linux de la sesión; en `frontend/` no se incluye `node_modules`.
En tu PC ejecuta `npm install` y `npm run dev` dentro de `frontend/` y, para la entrega, reemplaza las capturas por las de tu terminal y tu navegador.
